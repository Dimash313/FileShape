### 2026-11-15 security finding

`services.audio_tools.probe_audio` on current main can accept a text FFconcat manifest disguised as WAV, causing FFprobe to follow an additional local file. Issue #134 and draft PR #143 add early content-signature and actual-demuxer validation to prevent this. The security PR is stacked on #89 to avoid modifying its source branch. Draft #116 tests were updated to use actual tiny PCM inputs instead of nonexistent mocked probe paths; this retains compatibility with early validation. Do not activate audio join, trim, metadata or video ingestion without validating the final integrated security change and real-user isolation in all ingress routes.
